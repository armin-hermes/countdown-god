# ساعت مطالعه کنکور — countdown-god

اپ تک‌فایل فارسی (PWA) برای مطالعه کنکور: تایمر تمرکز/استراحت، برنامه هفتگی، آمار و کارنامه تحلیلی.

## برنامه هفتگی و سینک با تایمر

- برای هر درس در هر روز هفته می‌توان **چند تسک جدا** ست کرد؛ هر تسک عنوان و دقیقه خودش را دارد (مثلاً ریاضی شنبه: «درسنامه فصل ۳» ۵۰ دقیقه + «تست‌زنی» ۴۰ دقیقه).
- تایمر و برنامه **کاملاً سینک** هستند: دقیقه‌هایی که با تایمر روی یک درس مطالعه می‌شود، به‌صورت خودکار از تسک‌های همان درس در همان روزِ هفتهٔ جاری (شنبه تا جمعه) کم می‌شود.
- کم‌شدن به‌ترتیب ساخت تسک‌هاست: اول تسک‌های زودتر پر می‌شوند، سرریز به تسک بعدی می‌رسد؛ برای هر تسک «چند دقیقه مانده» نمایش داده می‌شود.
- موفقیت هفته بر اساس دقیقه حساب می‌شود: مجموع دقیقهٔ انجام‌شده تقسیم بر مجموع دقیقهٔ برنامه.
- تیک دستی هنوز هست و روی محاسبهٔ تایمر اولویت دارد.
- داده‌های قبلی (`god.plan.v1`) بدون تغییر فرمت خوانده می‌شوند؛ ورودی‌های قدیمیِ روزانه هم سر جایشان می‌مانند.

## تایمر: شروع از برنامه، کرنومتر آزاد، اضافه‌کار

- روی هر تسک برنامه دکمهٔ شروع هست: درس و دقیقهٔ تایمر از خود تسک ست و نشست آغاز می‌شود.
- تب «کرنومتر آزاد»: شمارش رو به بالا بدون سقف؛ دکمهٔ «پایان و ثبت» دقیقه‌ها را مثل یک نشست عادی ثبت می‌کند و از برنامه کم می‌شوند.
- وقتی شمارش معکوس تمرکز به صفر می‌رسد، نشست خودکار بسته نمی‌شود: «اضافه‌کار» با علامت + شروع می‌شود (حتی اگر تب خواب بوده باشد، از زمان واقعی صفر حساب می‌شود) و با «پایان نشست و استراحت» مجموع زمان برنامه + اضافه‌کار ثبت می‌شود.
- عوض‌کردن تب (تمرکز/استراحت/کرنومتر) وسط نشست، دقیقه‌های گذشته را زیر همان درس ثبت می‌کند؛ چیزی گم نمی‌شود.

## اجرا

فایل‌های استاتیک در `public/` هستند و با GitHub Pages (workflow: `.github/workflows/gh-pages.yml`) منتشر می‌شوند. ذخیره‌سازی کاملاً محلی است (localStorage). تست‌ها: `npm test`.

## نسخه اندروید (APK)

همان وب‌اپ، با پوستهٔ Capacitor — بدون بازنویسی:

- **تایمر زنده:** نشست فعال با زمان‌مهر (تاریخ پایان/شروع، نه تیک) در `god.session.v1` ذخیره می‌شود؛ با بستن یا کیل‌شدن اپ چیزی گم نمی‌شود. نشست‌های رهاشدهٔ بالای ۱۲ ساعت دور انداخته می‌شوند و دقیقهٔ فانتوم ثبت نمی‌کنند.
- **اعلان نیتیو:** پایان تمرکز/استراحت با `@capacitor/local-notifications` زمان‌بندی می‌شود و حتی وقتی اپ بسته است می‌آید (بعد از ری‌استارت گوشی هم باززمان‌بندی می‌شود). یادآور روزانه هم همین‌طور. صدای اعلان `timer_done.mp3` است (در `android/app/src/main/res/raw/`).
- **جزئیات اندروید:** نوار وضعیت هماهنگ با تم روشن/تیره، دکمهٔ برگشت اول به تب تایمر برمی‌گردد، ذخیرهٔ نشست هنگام پس‌زمینه رفتن اپ. هدر اپ زیر نوار وضعیت گوشی نمی‌رود (safe-area + `setOverlaysWebView(false)`) و در اولین اجرا تم روشن/تیره از پیش‌فرض دستگاه گرفته می‌شود.
- **بیدار نگه داشتن صفحه:** حین تمرکز (و کرنومتر آزاد) صفحه خاموش نمی‌شود؛ از تنظیمات قابل خاموش کردن است. موقع استراحت صفحه طبق معمول خاموش می‌شود.
- **بک‌آپ و بازیابی:** خروجی یک فایل JSON از همهٔ داده‌ها (برنامه، آمار، کارها، یادداشت‌ها، تنظیمات) — در اپ با اشتراک‌گذاری فایل، در وب با دانلود. بازیابی با تأیید قبلی و اعتبارسنجی فایل انجام می‌شود.
- **بروزرسانی درون‌برنامه‌ای (فقط اندروید):** از بخش امکانات، «بررسی بروزرسانی» آخرین ریلیز گیت‌هاب را با نسخهٔ نصب‌شده مقایسه می‌کند؛ اگه نسخهٔ جدیدتر بود، APK را دانلود و نصب‌کنندهٔ سیستم را باز می‌کند (پلاگین نیتیو `AppUpdater`، ثبت‌شده در `MainActivity`؛ نیاز به اجازهٔ `REQUEST_INSTALL_PACKAGES` دارد). بخش نصب PWA و نمای ویجت در نسخهٔ اندروید مخفی است.
- اسم اپ در اندروید **TimerO** است (package همان `com.arminhermes.countdowngod` می‌ماند).
- نسخهٔ وب دست‌نخورده می‌ماند: همهٔ فراخوانی‌های نیتیو گارد شده‌اند و روی timer.us.ci نو-آپ هستند. یادآور وب هم حالا واقعاً سر ساعت (درحالی‌که صفحه باز است) اعلان می‌دهد — قبلاً فقط تنظیمش ذخیره می‌شد.

### بیلد و انتشار

- بیلد APK با GitHub Actions انجام می‌شود (workflow: `.github/workflows/android.yml`): روی هر PR و پوش به main فقط بیلد و تست می‌شود؛ روی تگ `v*` (مثلاً `v1.1.0`) فایل APK به GitHub Releases منتشر می‌شود. آیکون‌ها، اسپلش‌ها، صدای نوتیف و gradle-wrapper.jar در گیت نیستند و CI آن‌ها را موقع بیلد می‌سازد.
- بیلد محلی: `npm ci && npx cap sync android`، بعد `python3 scripts/generate-android-assets.py` و `cp public/sounds/school_bell.mp3 android/app/src/main/res/raw/timer_done.mp3`، و بعد باز کردن `android/` در Android Studio (نیاز به JDK 21 و Android SDK با API 36 دارد؛ Android Studio فایل gradle-wrapper.jar را خودش می‌سازد). اگه از خط فرمان با `./gradlew` بیلد می‌گیری، اول `chmod +x android/gradlew` بزن.
- آیکون و اسپلش از `public/icons/icon-512.png` ساخته می‌شوند؛ بعد از عوض کردن آیکون، `python3 scripts/generate-android-assets.py` را اجرا کن.
- شمارهٔ نسخه: `package.json` و `android/app/build.gradle` (`versionName` + `versionCode`) را با هم بالا ببر — برای اینکه بروزرسانی درون‌برنامه‌ای کار کند، `versionCode` هر ریلیز باید از قبلی بیشتر باشد.
